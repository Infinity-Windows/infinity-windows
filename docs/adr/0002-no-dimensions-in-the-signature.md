# No dimensions in the signature; sizes are continuous evidence

The signature is a grouping key, and every field in it splits cohorts. Exact sizes would make each unit a cohort of one; size buckets would spend forever arguing edges. We decided (owner, 2026-08-16) the signature carries only categorical facts — kind, mechanism tally, panel/moving counts, corner presence, story per tier, inset/outset — and **sizes never enter it**: panel weight (from Strata, per panel) and dimensions scale the per-panel cost as continuous inputs to the evidence model instead. The same mirror-image logic excludes handedness everywhere: XO = OX, left corner = right corner (side kept as a descriptive field). The signature is versioned (`v`) so definition changes recompute forward without silently fracturing cohort history.
